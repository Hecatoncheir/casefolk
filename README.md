# Casefolk

Демонстрационный сайт мастерской персональных компьютеров: главная страница, конструктор внешнего вида MODCASE HYPER и библиотека SVG.

Сайт: https://hecatoncheir.github.io/casefolk/

## Возможности

- Выбор материала, цвета рамы и панелей, размера, типа панели и вентиляторов.
- Стилизованный векторный предпросмотр, включая вид внутри.
- Пожелания по комплектующим, итоговый состав и скачивание JSON.
- Локальные черновик и сохранённый вариант: последующее редактирование черновика не меняет сохранение.
- Страница `brand.html` с отдельными SVG и архивом.
- Работа по вложенному пути GitHub Pages, адаптивная вёрстка и управление с клавиатуры.
- Аккуратные переходы между экранами, плавная смена цветов и поддержка системной настройки уменьшения движения.

Это демонстрационный проект: заявки и платежи не принимаются. Значения на экране не подтверждают физическую совместимость деталей, наличие материалов, стоимость или готовность к изготовлению. Персональные данные не запрашиваются; выбранные параметры сохраняются только в браузере посетителя. Аналитики и внешних сервисов в сайте нет.

## Запуск

Требуется Node.js 22 или новее.

```sh
npm ci
npm run check
npm test
npm run build
npm run dev
```

Откройте http://127.0.0.1:4173/casefolk/ . Конструктор использует ES-модули, поэтому сайт нужно запускать через HTTP, а не открывать `index.html` как локальный файл.

```sh
# Для браузерных проверок в Linux:
npx playwright install --with-deps chromium
CI=true npm run test:browser

# Локально в Windows используется установленный Chrome:
npm run test:browser
```

## Файлы

- `index.html`, `styles.css`, `js/` — самостоятельный сайт без зависимости от Codex.
- `assets/svg/` — логотип, надпись, персонаж, favicon, восемь иконок и общий лист.
- `downloads/casefolk-svg.zip` — архив SVG для скачивания.
- `assets/fonts/` — локальные Nunito (заголовки), Nunito Sans (интерфейс), JetBrains Mono (технические параметры) и их лицензии SIL Open Font License.
- `tests/` — проверки конфигурации, хранения и браузерных сценариев.
- `.github/workflows/pages.yml` — проверки и публикация содержимого `dist/` через GitHub Actions.

## Графика и модель корпуса

Айдентика векторизована по выбранному пользователем концепту Casefolk, созданному с помощью ImageGen. В SVG находятся настоящие контуры, включая контуры надписи; PNG, JPEG и ссылки на растровые подложки не встроены. Трассировка сохраняет характер исходного эскиза, но не является ручной перерисовкой геометрии.

Рисунок корпуса в конструкторе — самостоятельная схематичная иллюстрация интерфейса. Название и конструкция MODCASE HYPER принадлежат MODCASE / Haydn Bao. Коммерческое изготовление требует соответствующих прав. Исходные 3MF, STEP, Fusion 360, коммерческая лицензия и другие файлы модели в этот репозиторий не входят.
